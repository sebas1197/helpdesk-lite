# HelpDesk Lite

HelpDesk Lite es una aplicación web sencilla para la gestión de tickets de soporte.

## Release actual

Versión en preparación: 1.3

## Funcionalidades principales

- Registro de tickets
- Validación de información
- Clasificación por prioridad
- Seguimiento de solicitudes

## Objetivo de calidad

Antes de liberar la versión 1.3, el equipo debe comprobar que:

- no existan modificaciones accidentales;
- la configuración corresponda al ambiente esperado;
- todos los cambios se encuentren registrados;
- el repositorio se encuentre actualizado;
- exista trazabilidad sobre la revisión realizada.
